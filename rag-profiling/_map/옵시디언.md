# 옵시디언으로 이 스킬 보기

이 폴더(`rag-profiling/`)를 볼트로 열면 스킬 구조를 그림으로 본다.
문서 원본은 건드리지 않는다. `_map/` 의 두 파일만 생성물이다.

## 여는 법

1. 옵시디언 실행 → **다른 볼트 열기** → **폴더를 볼트로 열기**
2. `C:\Users\ghwls\.claude\skills\rag-profiling` 선택
3. 왼쪽 파일 목록에서 `_map/구조.canvas` 열기

볼트 루트를 상위 `skills/` 로 잡지 않는다. 스킬 157개가 전부 색인돼 그래프를 못 쓴다.

## 무엇을 보나

| 파일 | 쓰임 |
|---|---|
| `_map/구조.canvas` | **주 화면.** 참조 문서 9개가 카드로 놓이고 선 14개로 이어진다. 카드를 클릭하면 원본이 열린다. 왼쪽 끝 `SKILL.md` 는 진입점이라 선을 안 그린다(9개를 전부 가리켜 화면만 덮는다) |
| `_map/문서참조그래프.md` | 같은 그래프의 mermaid 판. 참조가 몰리는 곳과 엣지 표가 붙어 있다. GitHub 에서도 렌더된다 |

카드는 원본을 가리키는 링크다. 사본이 아니라서 원본을 고치면 카드 내용도 같이 바뀐다.
다만 **참조선은 자동으로 안 따라온다.** 문서를 고쳐 참조가 늘거나 줄었으면 다시 만든다.

```bash
python _map/build.py            # 다시 만든다
python _map/build.py --check    # 어긋났으면 종료코드 1
```

## 플러그인: 필요 없다

**Canvas 와 mermaid 는 옵시디언 코어 기능이다.** 커뮤니티 플러그인을 하나도 안 깔아도 위 두 파일이 그대로 동작한다.

Canvas 가 안 보이면 **설정 → 코어 플러그인 → Canvas** 가 켜져 있는지만 본다.

## 커뮤니티 플러그인을 깔고 싶을 때

1. **설정**(왼쪽 아래 톱니) → **커뮤니티 플러그인**
2. **제한 모드 끄기** (첫 설치 때 한 번)
3. **탐색** → 이름 검색 → **설치** → **활성화**

깔 만한 것과 이 볼트에서의 실익:

| 플러그인 | 얻는 것 | 판단 |
|---|---|---|
| **Git** | 볼트 안에서 바로 커밋·푸시. 이 폴더가 곧 저장소라 스킬을 고치고 옵시디언을 안 나가도 된다 | 실익 있음 |
| **Excalidraw** | 손으로 그린 도해를 노트에 붙인다. 자동 생성 그래프로 안 되는 설명용 그림 | 필요할 때만 |
| **Dataview** | 노트 목록을 쿼리로 표에 뽑는다 | **불필요.** `build.py` 가 이미 표를 만든다 |
| **Juggl · Graph Analysis** | 그래프 뷰 강화 | **효과 없음.** 원본이 파일명을 백틱 평문으로 적어 링크가 아니다. 강화할 링크 자체가 없다 |

마지막 줄이 이 볼트의 제약이다. **옵시디언 기본 그래프 뷰에는 참조선이 안 그려진다.**
원본에 링크를 박지 않기로 했기 때문이고, 그래서 참조 그래프를 `구조.canvas` 로 따로 만든다.

## 커밋 범위

`.obsidian/` 은 `.gitignore` 에 있다. 창 위치·테마처럼 PC 마다 다른 값이라 올리면 충돌만 낸다.
`_map/` 세 파일은 커밋한다.
