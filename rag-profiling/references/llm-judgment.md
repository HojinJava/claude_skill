# LLM 판정: 3단계

정규식과 SQL 로는 **빈도까지만** 알 수 있다.
"이 조각이 단독으로 답변 근거가 되는가"는 의미 판정이라 직접 읽어야 한다.

---

## LLM 은 한 자리가 아니라 다섯 자리에서 개입한다

| 단계 | 하는 일 | 실제 사례 |
|---|---|---|
| 1a | 도메인 지식 → 가설 → 측정 항목 도출 | 위계·부속물·참조 방식을 알아야 가설이 선다 |
| **3** | **의미 판정** (자립성 · 제외 여부) | 층화 표본 12건 정독 |
| **4** | **실패 원인 분류** | 링크 실패를 읽어 4종으로 가름 → 보정 규칙 3종 |
| 5 | 가설 기각 판단 · 결과 해석 | H3 기각 |
| 6 | 재적용 결과 해석 | 길이 상한 미준수 발견 → 슬라이딩 추가 |

**4번이 특히 중요하다.** 1차 링크율 47.6% 로 기각 직전이던 가설을,
실패 사례를 직접 읽어 "표기 문제 3종 + 구조적 한계 1종"으로 가르자 **73.3%** 가 됐다.
정규식으로는 못 하는 판단이고, 이게 설계를 살렸다.

---

## 표본 뽑는 법

**층화 표본 + 시드 고정.** 무작위 N건은 다수 유형만 뽑혀 예외를 못 본다.

```python
import random
random.seed(39)          # 반드시 고정하고, 문서에 시드를 적는다
picks = []
for stratum, items in groups.items():        # 종류·길이대·상태 등으로 나눈다
    picks += random.sample(items, min(3, len(items)))
```

- **10~40건**이면 대개 충분하다. 판정이 안 갈리면 늘려도 안 갈린다.
- 층은 **결정에 영향을 주는 축**으로 나눈다 (문서 종류, 길이 구간, 결측 여부).
- 실패 사례를 볼 때는 **실패한 것만** 층화한다. 성공 표본은 정보가 없다.

---

## 루프 규율: 무작정 반복하지 않는다

여기서 말하는 반복은 **표본을 몇 번 더 읽을 것인가**다.
루프 자체를 언제 또 도는가는 `orchestration.md` 의 `루프` 에 있다.

```
표본을 더 읽는다:  판정이 갈리는데 표본이 그 갈림을 못 덮는다
멈춘다:  ① 수치로 판정됨            → 확정
        ② 표본을 읽어도 안 갈림      → 미해결 4필드로 남기고 다음 루프
```

②를 그냥 넘기면 같은 걸 다음 루프에 또 판정한다. **반드시 4필드로 남긴다** →
`미확정 사유 / 해결 방법 / 판정 기준 / 언제(Phase)`
그 `해결 방법` 이 원장의 `next_measure` 가 되고, 다음 루프가 그것만 보고 돈다.

---

## 판단은 흔적을 남긴다

표를 4열로 고정한다.

```
판정 대상        | 규모     | 판정                              | 규칙 반영
────────────────┼─────────┼──────────────────────────────────┼──────────────────
조각 자립성       | 표본 12건 | 상위 계층: 자립 / 하위 계층: 불성립   | prefix 에 관계 명시
최소 길이 조각     | 7,555건  | 제외 불가 · 예외 2종               | 길이 하한 미적용
```

**표본 시드를 함께 적는다.** 안 그러면 재현이 안 되고 다음 루프에 같은 걸 또 판정한다.

---

## 판단이 갈리면 원본을 직접 센다

검토자를 여럿 병렬로 돌리면 판정이 충돌한다(실제 사례에서 3건).
**다수결로 정하지 않는다.** 수치를 뒤집는 판단은 원자료로 되짚어 확인한다.

실제 사례에서 `49 vs 16`, `12,115 vs 12,120 vs 12,349`, 마커 범위가 전부 이 방식으로 갈렸다.
같은 이름의 지표에 값이 셋이면 대개 **정의가 셋**이다. 스코프를 명기해 남긴다.

## LLM 을 호출로 쓸 때

평가·판정에 LLM 호출이 필요한데 API 키·예산이 없으면
`claude-cli-llm-server` 스킬로 로컬 CLI 를 OpenAI 호환 엔드포인트로 띄운다.

**주의**: 판정은 **재현 가능해야** 한다. 프롬프트·시드·모델을 기록하지 않은 판정은
다음 루프에 못 쓴다. 표본 목록과 프롬프트를 산출물로 남긴다.
